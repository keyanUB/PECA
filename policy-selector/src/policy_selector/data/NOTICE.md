# OWASP policy source attribution

The bundled `owasp-checklist.md` is an unmodified snapshot of the OWASP Secure
Coding Practices Quick Reference Guide's `stable-en` checklist, downloaded from
the official OWASP project repository on 2026-09-09.

Copyright OWASP Foundation and contributing authors.

Source: https://owasp.org/www-project-secure-coding-practices-quick-reference-guide/stable-en/02-checklist/05-checklist

Repository: https://github.com/OWASP/www-project-secure-coding-practices-quick-reference-guide

The original guide is released under Creative Commons Attribution-ShareAlike 3.0:
https://creativecommons.org/licenses/by-sa/3.0/

The OWASP website also states a default Creative Commons Attribution-ShareAlike
4.0 license unless otherwise specified: https://creativecommons.org/licenses/by-sa/4.0/
The original guide's explicit license is retained for the checklist and derivative
JSON catalog. This notice does not assign that license to PECA's Python code.

`owasp-scp.json` is a mechanical adaptation: checklist entries are split into
records, continuation lines joined, escaped quotes normalized, source links added,
and PECA-specific content-derived IDs assigned. These are not official OWASP IDs.
The raw source SHA-256 is included in the JSON source metadata.

This historical checklist contains dated recommendations. Selection does not
constitute OWASP endorsement, a current-standard audit, or proof of compliance.
